# Скиллы для аккаунта claude.ai

Каждый ZIP - один скилл. Установка: claude.ai → Customize → Skills (https://claude.ai/customize/skills) → Add → Upload skill → выбрать ZIP.

Порядок важности:
- **Свои:** skills-catalog, tripo-3d-presets, game-production-pipeline
- **Дизайн:** ui-ux-pro-max, design, brand, banner-design, slides + design-system (ставить вместе), ui-styling
- **Игры:** game-feel, game-design-theory, level-designer, game-ui-ux, game-vfx, multiplayer-game-architecture, game-performance-profiler, web-game-development
- **Тексты:** infostyle
- **Графика и видео (свои, по мотивам Scenario):** game-art-qa, game-art-production, game-trailer-video

Источники и лицензии указаны в metadata каждого SKILL.md и в файле LICENSE внутри архива.
