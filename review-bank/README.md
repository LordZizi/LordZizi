# Конструктор игр

Конструктор 2D-игр (жанр + две механики + сеттинг) и банк отзывов Steam о похожих играх - для моей будущей 2D-игры.

- **Живая страница:** https://claude.ai/artifact/N5z4M4sYfaQZPSwUauPPsn - данные в базе страницы (игры, отзывы, свои жанры/механики/сеттинги, галочки «Учесть»).
- **Копия в репозитории** (чтобы любая ветка и сессия могла править и дополнять):
  - `index.html` - исходник страницы; встроенные списки `GENRES`, `MECHS`, `SETTINGS`, `TWISTS`, `QUOTES`;
  - `data/games.json`, `data/insights.json`, `data/parts.json` - выгрузка базы (ключ - id документа);
  - `games/<игра>.md` - читаемый разбор каждой игры;
  - `tools/` - скачивание отзывов Steam (`community_paged.py`) и выгрузка базы (`export_db.py`);
  - `../.claude/skills/game-constructor/` - скилл для Claude: как пополнять конструктор. Claude Code видит его в любой сессии и ветке этого репозитория сам; ZIP для claude.ai: `../skills-zip/game-constructor.zip` (Customize → Skills → Upload).

## Как пополнять

- **На странице:** раздел «Мастерская» - вкладки Игра, Отзыв, Жанр, Механика, Сеттинг, «Из игры-референса» (Claude предлагает механики и жанры игры) и «Мои добавления» (удаление).
- **Через Claude:** «Разбери отзывы игры НАЗВАНИЕ в банк отзывов и добавь её механики в конструктор». Подробный порядок и форматы - в `.claude/skills/game-constructor/SKILL.md`.
- **Встроенные списки:** правка `index.html`, публикация на тот же url, коммит.

## Как добавить игру (подробно)

Напишите Claude: **«Разбери отзывы игры НАЗВАНИЕ в банк отзывов»**. Порядок для сессии:

1. Скилл steam-reviews: найти AppID, общую оценку со страницы магазина, патчи.
2. Отзывы: API Steam (`store.steampowered.com/appreviews`) из облака отвечает переадресацией, поэтому качать со страниц сообщества:
   `python3 tools/community_paged.py APPID out.jsonl` (нужен доступ к steamcommunity.com в сетевых настройках среды).
3. Прочитать отзывы, выделить темы, записать в базу страницы (ArtifactData, url выше):
   - `games/<id>`: name, appid, url, genre, price, positivePct, reviewsTotal, sample, analyzedAt, released, summary;
   - `insights/<id>`: game, type (like | dislike | request | idea | takeaway), theme, text, share (% выборки), quotes [{text, url, lang}], forMyGame ("" или "use").
   Держать по 5-8 строк на тип: страница показывает топ-5 в каждой колонке.
4. Обновить эту копию: выгрузить коллекции в `data/*.json`, пересобрать `games/*.md`, закоммитить.

## Формат строк

- **Нравится / Не нравится** - что игроки хвалят и ругают, с долей выборки.
- **Просят** - просьбы и идеи игроков.
- **Выводы** - что из этого следует для дизайна моей игры.
